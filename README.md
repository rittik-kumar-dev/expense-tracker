# Expense Tracker

A simple command-line Expense Tracker built with Python.

## Features

* Add expenses
* View all expenses
* Store data using JSON
* Persistent data storage
* Input validation
* Error handling using try-except

## Technologies Used

* Python
* JSON
* File Handling

## Project Structure

expense_tracker.py → Main application

savelist.json → Stores expense data

## Concepts Practiced

* Functions
* Lists
* Dictionaries
* JSON Handling
* Exception Handling
* File Operations

## Future Improvements

* Delete expense feature
* Expense categories
* Monthly reports
* GUI version
* MySQL integration
